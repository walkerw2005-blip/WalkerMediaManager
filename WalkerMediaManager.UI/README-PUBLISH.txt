WALKER MEDIA MANAGER - PORTABLE BUILD

1. Close Visual Studio.
2. Double-click Publish-Portable.cmd.
3. Wait for the publish process to finish.
4. Open Publish\WalkerMediaManager.
5. Run WalkerMediaManager.exe from that folder.

IMPORTANT:
- Keep every file in the Publish\WalkerMediaManager folder together.
- Do not copy only WalkerMediaManager.exe to the desktop.
- Create a shortcut to the EXE instead.

If startup fails, the app now displays the actual error and writes a log here:
%LOCALAPPDATA%\WalkerMediaManager\Logs\walker-media-manager.log
